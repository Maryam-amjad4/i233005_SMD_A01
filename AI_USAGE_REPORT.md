# AI Usage Report

The completed official instructor template is [AI_USAGE_REPORT.pdf](AI_USAGE_REPORT.pdf).

An editable copy is provided in [AI_USAGE_REPORT.docx](AI_USAGE_REPORT.docx). Student identity, date and signature fields are left blank for the submitting student. The declaration must be reviewed and completed by that student. The report distinguishes AI-assisted development, automated verification and the supplied Android phone screenshots. The application uses no runtime AI service.
