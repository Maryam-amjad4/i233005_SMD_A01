# Android phone evidence

These six original screenshots were supplied after launching Flex++ through Expo Go using QR scanning. They show the Home dashboard, attention cards, attendance bar chart, cumulative-GPA line chart, module standings and shortcuts at different scroll positions.

The Android system bars and Expo Go overlays are retained. No images were synthesized or edited. These images establish the displayed Home views; they do not demonstrate course forms, task validation, hardware Back, keyboard behavior or restart persistence. The bundling/splash capture is excluded because it does not show application behavior.
